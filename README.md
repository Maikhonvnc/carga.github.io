# carga.github.io

https://maikhonvnc.github.io/carga.github.io/

## Desenvolvimento

- Código em `js/` (scripts simples, sem build), catálogo em `data.js`.
- Testes de ponta a ponta: `node tests/e2e.js` (precisa do Playwright).
- Nutrição: plano alimentar e tabela de alimentos em `dieta.js`, alimentos comuns com preparos e medidas caseiras em `alimentos-comuns.js`, telas em `js/nutricao.js`.
- `previa.html`: comparação das opções de desenho do corpo e de mídia.
